# 🗄️ Airtable CRM Database Schema

To track opportunities, AI-generated proposals, and application pipeline metrics, configure your Airtable base `Upwork_Jobs` with the following columns:

| Field Name | Field Type | Description / Format |
| :--- | :--- | :--- |
| **Job ID** | Single Line Text | Unique identifier extracted from Upwork URL |
| **Job Title** | Single Line Text | Title of the opportunity |
| **Job URL** | URL | Direct clean link to Upwork job post |
| **Posted At** | Date / Time | Timestamp when opportunity was published |
| **Budget** | Single Line Text | E.g. `$1,500 (fixed)` or `$40-$60/hr` |
| **Opportunity Score** | Number | Calculated 0–100 Intelligence Score |
| **Priority** | Single Select | `High Priority`, `Worth Reviewing`, `Low Priority`, `Ignore` |
| **Matched Skills** | Multiple Select / Text | E.g. `n8n`, `OpenAI`, `Python`, `API Integration` |
| **Client Rating** | Number | Star rating (0.0 to 5.0) |
| **Client Spend** | Currency / Number | Total client USD spent on Upwork |
| **AI Proposal** | Long Text | High-converting proposal draft generated by OpenAI |
| **Status** | Single Select | `Ingested`, `Drafted`, `Approved`, `Submitted`, `Interviewing`, `Hired`, `Rejected` |
| **Notes** | Long Text | Review notes or custom edits made before submission |
